Vaporwave Interactive Experience - Reece Whitaker

This is a project completed in September 2026 as the first project for my Graphics Programming course. Visuals were inspired by vaporwave style scrolling screensavers. See [TODO: INSERT LINK] for full documentation.

The project has 3 render modes: wireframe, pixel edges, and pixel faces. Where wireframe uses js canvas' built in line drawing with x,y generated using pinhole projection. Pixel edges and pixel faces use rasterization on a simualted 320x200 pixel display. Pixel edges uses a line rasterization algorithm to draw edges, while pixel faces uses a triangle rasterization algorithm to draw faces. All objects represented in real space and transformed into uv projection.

Controls: WASDQE or arrow keys, '.', ',' to move within bounds, SPACE to change car color, R to reset, Z to show wireframe in faces mode, 123 to change mode, F to view pixel grid.
