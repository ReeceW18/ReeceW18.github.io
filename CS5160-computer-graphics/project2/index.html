Cube World - Reece Whitaker

This project was completed for my Computer Graphics course to explore using WebGL 2 to render graphics using real GPU pipelines. See technical documentation on my website or view the source code on GitHub.

The application utilizes WebGL shaders, specifically instanced rendering to efficently render massive voxel landscapes in real time directly on the gpu. It features two modes:

  • Procedural Mode: Generates terrain heights on-the-fly using layered sine/cosine waves and generates colors based on those heights. It also includes a simple boat traveling along a cubic Bézier curve.
  • Image Mode: Loads exaggerated height and color maps of Cincinnati as textures and uses the GLSL texture sampler inside the shader.
⚠️ WARNING: Higher values increase cubes quadratically (e.g. 10 = 1,000 grid size / 1,000,000 cubes / 36M vertices). Up to 10 should be reasonable on most devices, up to 30 on high end devices, and the text box goes up to 50 if you want to push it. Setting this too high can lag, freeze, or crash your browser/GPU.
