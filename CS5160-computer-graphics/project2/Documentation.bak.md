# AI Disclosure
I generally wrote all code myself but when I didn't know how to do something I would turn to AI for help.

I had a single gemini-flash chat in my IDE sidebar, which ended up being around 500k tokens. which I used to ask how to do anything that I didn't already know how to do, I typically ask for examples, analyze the example to fully understand it then implement it in the project.

For formulas I would attempt deriving myself but if I had trouble I would turn to AI and then tweak its formula to better fit what I had in mind. For example the terrain generation formulas were generated by AI but I tweaked the constants and added a offset to center it where I wanted.

It was a lifesaver in wrapping my head around some concepts, sure with these non-flagship models hallucinations can still be a problem but being able to ask specific questions and get a psuedo-expert response makes learning so much easier and quicker than staring at documentation for hours, although documentation can still be useful in its own ways. It helped a ton with understanding how binding of programs and variables worked and what exactly each command was actually doing under the hood.

Another example of usage is when I was trying to figure out how to add the image mode it generated example code for loading and sampling textures and adding a toggle between image and procedural mode. I walked through it making sure I understood every line and then implemented it, although I ended up copying it almost line for line as it was pretty much exactly what I had in mind.

An example of where I had to use my judgement to override it was in addng the user override of the max multiplier. I asked for it to add those controls to the ui and wire it into the JS but what it generated was both typical overcomplicated ai code and directly modified the grid-size instead of the multiplier, so I went through and rewrote it all to match my vision and remove unnecessary components.

Also helped speed up the cleanup process at the end, clearing out dead code, moving things around to be better style, etc.
